Quick Guide

for loop: repeats a block of code for each value in a sequence.

range(1, 6): produces 1, 2, 3, 4, and 5. The ending value, 6, is not included.

import time: makes Python's time module available to the program.

time.sleep(1): pauses the program for one second.

Indentation: print() and time.sleep(1) must be indented under the for statement so they repeat during every iteration.

Scenario

You've probably heard children count “one Mississippi, two Mississippi” during games such as hide-and-seek. In this lab, you will simulate that counting with Python. The program will count from 1 to 5, pause one second between each count, and then display “Ready or not, here I come!”

Task 1 — Import the Time Module

At the beginning of your program, import Python's time module. This lets the program pause between counts.

Code:

import time

Task 2 — Write the for Loop

Create a for loop that counts from 1 through 5. Remember: the ending value in range(1, 6) is not included, so the values produced are 1, 2, 3, 4, and 5.

Code:

for second in range(1, 6):
    print(second, "Mississippi")

Task 3 — Add the One-Second Pause

Inside the loop, add time.sleep(1) after the print(). Because it is indented inside the loop, Python pauses for one second after each count.

Code:

for second in range(1, 6):
    print(second, "Mississippi")
    time.sleep(1)

Task 4 — Print the Final Message

After the loop finishes counting to 5, print the final message. This line must not be indented because it should run only after the loop has finished.

Code:

print("Ready or not, here I come!")

Task 5 — Test the Complete Program

Run your completed program. Watch the output carefully. It should pause about one second between each Mississippi count and then display the final message.

Expected Output:

1 Mississippi
2 Mississippi
3 Mississippi
4 Mississippi
5 Mississippi
Ready or not, here I come!
