Lab 31: Understanding Variable Scope and the global Keyword

Learn why a variable inside a function is different from a variable outside it.

Learning Objectives

Learn why a variable inside a function is different from a variable outside it. Practice function calls, code indentation, and checking results.

TASK 1

Create the global counter

Enter the following code in the Python file you already opened.

my_counter = 10
Line-by-line and indentation guide

• 0 spaces: This line starts at the left edge.

• `my_counter` stores the starting value 10 outside all functions.

TASK 2

Create a local function

Add this function below the existing code. Leave a blank line before it.

def add_to_local():
    my_counter = 5
    my_counter = my_counter + 1
    print("Inside local function, counter is:", my_counter)
Line-by-line and indentation guide

• 0 spaces: `def` begins at the left edge.

• 4 spaces: All three lines inside the function line up.

• The local counter starts at 5, increases to 6, and prints 6. It does not change the counter outside the function.

TASK 3

Create a global function

Add this second function below the first one.

def add_to_global():
    global my_counter
    my_counter = my_counter + 1
    print("Inside global function, counter is:", my_counter)
Line-by-line and indentation guide

• 0 spaces: `def` aligns with the earlier `def`.

• 4 spaces: `global`, assignment, and `print` align inside the function.

• `global my_counter` tells Python to change the outside variable, from 10 to 11.

TASK 4

Call the functions and run

Add these lines at the bottom, outside both functions. Run the complete file.

print("--- Calling functions ---")
add_to_local()
add_to_global()
print("--- After functions ---")
print("Global counter is now:", my_counter)
Line-by-line and indentation guide

• 0 spaces: Every line here starts at the left edge; none is inside a function.

• The first call prints 6 using a local variable. The second changes the global variable to 11.
