A Leap Year: Writing Your Own Functions

Build a Python function that determines whether a year is a leap year, then test it using the provided test cases.

Objectives

  • Write a parameterized function.
  • Use the return statement effectively.
  • Test the function with predefined test cases.

Quick Guide

Function: A reusable block of code defined with def. A function runs when you call it.

Parameter: In def is_year_leap(year):, year receives the value passed into the function.

return: Sends True or False back to the caller and immediately finishes the function.

Remainder %: year % 4 == 0 means that dividing the year by 4 leaves no remainder.

Why check 100 and 400? Most years divisible by 4 are leap years, but century years divisible by 100 are exceptions unless they are also divisible by 400.

Example: 1900 is divisible by 100 but not 400, so it is not a leap year. 2000 is divisible by 400, so it is a leap year.

Scenario

Write a function named is_year_leap(year) that decides whether a given year is a leap year. A year is a leap year if it is divisible by 4 but not 100, or if it is divisible by 400. After writing the function, compare its answers against the four predefined test cases from the lab guide.

Decision path

1. Not divisible by 4 → return False.
2. Otherwise, not divisible by 100 → return True.
3. Otherwise, not divisible by 400 → return False.
4. Otherwise → return True.

Indentation Quick Reference — Read Before Coding

Python uses 4 spaces per indentation level. A line ending in a colon (:) starts a block; the following line must be indented 4 more spaces. Statements in the same block must line up. To leave a block, move back 4 spaces (dedent). Do not mix tabs and spaces.

def example():          # 0 spaces
    if True:           # 4 spaces
        print("Hi")    # 8 spaces
    print("Done")       # 4 spaces
print("Outside")        # 0 spaces

Understanding Indentation

The four branches (if, elif, elif, else) belong inside the function. Each return is indented under its branch. The test lists and for loop start at the left margin, outside the function. Inside the test loop, the comparison if/else checks whether the answer matches the expected result.

Complete Code — Review

After completing the tasks, compare your work with the complete program in the supplied guide.

def is_year_leap(year):
    if year % 4 != 0:
        return False
    elif year % 100 != 0:
        return True
    elif year % 400 != 0:
        return False
    else:
        return True

# Test data
test_data = [1900, 2000, 2016, 1987]
test_results = [False, True, True, False]

# Test the function
for i in range(len(test_data)):
    yr = test_data[i]
    print(yr, "-> ", end="")
    result = is_year_leap(yr)
    if result == test_results[i]:
        print("OK")
    else:
        print("Failed")
