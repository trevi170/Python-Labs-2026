Quick Guide

A leap year is divisible by 400, OR divisible by 4 but not by 100. Python uses % to find the remainder.

Indentation: Each level is 4 spaces. Lines inside def, if, or for move one level right.

Tip: Each task builds on the earlier code. Do not type duplicate function definitions.

Task 1 — Create the leap-year function

def is_year_leap(year):
    return year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)
Indentation: The def line starts at 0 spaces. The return line uses 4 spaces.
Line 1: Names the function and its year input.
Line 2 — read it in small pieces:
return sends a True/False answer back to the code that called the function.
year % 400 == 0 checks whether dividing the year by 400 leaves a remainder of zero (for example, 2000).
or means either the first rule or the rule in parentheses can make the answer True.
year % 4 == 0 checks whether the year divides evenly by 4.
and means the two checks inside the parentheses must both be True.
year % 100 != 0 checks that the year does not divide evenly by 100. != means “not equal to.”
Examples: 2000 → True (divisible by 400); 1900 → False (divisible by 100 but not 400); 2024 → True (divisible by 4, not 100).
Alignment: Keep this entire return statement on one line, indented 4 spaces under def.
