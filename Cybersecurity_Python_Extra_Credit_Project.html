Extra Credit Project: Build Your Own Cybersecurity Tool

Design, code, test, and explain an original Python program that addresses a cybersecurity problem.

Individual project50 pointsPythonSubmit in Blackboard
Your mission: Become a cybersecurity developer. Choose one project below (or propose your own), create a working Python program, test it with at least three cases, and explain how it works. You will write your own code rather than copy a complete solution.

1. Choose your project

Option 1 · Password Strength Checker

Evaluate passwords against basic security requirements.

  • Accept a password from the user.
  • Check length, uppercase, lowercase, digits, and special characters.
  • Display a strength rating and improvement suggestions.

Option 2 · Suspicious Login Detection

Analyze simulated login records.

  • Store success/failure events in a list, tuple, or dictionary.
  • Count failed logins by username.
  • Alert when failures exceed a chosen threshold.
  • Display a summary.

Option 3 · Security Log Analyzer

Examine a sample security-event text file.

  • Read simulated log events from a file.
  • Identify failed logins, access denied, and suspicious activity.
  • Count event types and flag items for investigation.

Option 4 · File Integrity Checker

Determine whether a local file has changed.

  • Select a file and calculate its SHA-256 hash.
  • Save a baseline hash and compare it later.
  • Report whether the file changed.

Option 5 · Cybersecurity Quiz

Create an interactive security-awareness quiz.

  • Include at least 10 questions.
  • Accept and evaluate answers.
  • Calculate a score and provide feedback.

Have another idea? You may propose a different cybersecurity-related Python tool for instructor approval.

2. Required Python concepts

Your program must demonstrate all of the following:

  1. At least two functions you create.
  2. Variables and appropriate data types.
  3. At least one if, elif, or else statement.
  4. At least one for or while loop.
  5. At least one list, tuple, or dictionary.
  6. User input or file input.
  7. Clear, meaningful output.
  8. Comments explaining important code sections.
  9. Basic error handling where appropriate.

Additional Python libraries are permitted. Identify any third-party libraries used.

3. Project development steps

  1. Select a cybersecurity problem. Choose an option above or obtain approval for your own idea.
  2. Plan your program. Identify its inputs, processing steps, and expected outputs.
  3. Write your Python code. Use GitHub Codespaces, VS Code, or another Python environment.
  4. Test at least three cases. Record the input, expected result, and actual result for each case.
  5. Explain your project. Answer the five reflection questions below and prepare your submission.

4. Project explanation questions

  1. What cybersecurity problem does your program address?
  2. How does your program work?
  3. Which Python programming concepts did you use?
  4. What challenges did you encounter?
  5. How could your program be improved?

Important guidelines

Use safe, authorized data and systems. Work with simulated records, your own files, or systems you have explicit permission to test. Do not collect real passwords or access computers or networks without authorization. Submit your own work; do not present a downloaded program as your own. Be ready to explain your code.

Remember: You do not need to build a professional cybersecurity application. Your goal is to demonstrate how Python can solve a practical cybersecurity problem.
