Lab Scenario

Miles and kilometers are both units of distance. In this lab, you will create a program that converts miles to kilometers and kilometers to miles.

Conversion reminder: 1 mile is approximately equal to 1.61 kilometers.

Task 1 — Assign Variables

Create two variables named miles and kilometers. The example values below match the sample results shown in the lab guide.

miles = 7.38 kilometers = 12.25

Line-by-line explanation: The first line stores a distance measured in miles. The second line stores a distance measured in kilometers.

Task 2 — Create the Conversion Logic

Create one variable to convert miles to kilometers and another to convert kilometers to miles.

miles_to_kilometers = miles * 1.61 kilometers_to_miles = kilometers / 1.61

Explanation: Multiplying by 1.61 converts miles to kilometers. Dividing by 1.61 converts kilometers to miles.

Task 3 — Print the Conversion Results

Use print() to combine strings and variables. Use round(value, 2) to display the converted values to two decimal places.

print(miles, "miles is", round(miles_to_kilometers, 2), "kilometers") print(kilometers, "kilometers is", round(kilometers_to_miles, 2), "miles")
Expected output: 7.38 miles is 11.88 kilometers 12.25 kilometers is 7.61 miles

Task 4 — Analyze the Code

Look closely at how the print() function accepts multiple arguments. Notice how strings and variables can be displayed together on one line.

Also observe how round() is placed directly inside print():

round(miles_to_kilometers, 2)

The first argument is the value being rounded. The second argument tells Python how many decimal places to keep.

Task 5 — Experiment in the Sandbox

Change the values and experiment with the converter. Then test how round() behaves with one, two, three, or no decimal-place argument.

value = 12.34567 print(round(value, 1)) print(round(value, 2)) print(round(value, 3)) print(round(value))
