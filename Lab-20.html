Quick Guide

.upper() converts the user's word to uppercase.

word_without_vowels = "" creates an empty string that will hold the consonants.

for letter in user_word: processes the word one character at a time.

continue skips the rest of the current iteration when a vowel is found.

+= performs string concatenation here. For example, word_without_vowels += letter adds the current consonant to the end of the string.

Scenario

Upgrade the earlier Vowel Eater. Instead of printing every uneaten letter on a separate line, store the consonants in a new variable called word_without_vowels. After the loop finishes, print the completed word without vowels all at once.

Code:

Task 5 — Skip the Vowels Using continue

Inside the loop, use the required if/elif checks for A, E, I, O, and U. If the current letter is a vowel, continue skips it.

Code:

if letter == "A":

    continue
elif letter == "I":
    continue

    continue

    continue

Task 6 — Add the Uneaten Letters

If the current letter is not a vowel, add it to word_without_vowels. The += operator appends the letter to the existing string.

Code:

else:

After the loop has finished, print word_without_vowels. This line belongs outside the loop so the completed word is printed only once.

Code:
