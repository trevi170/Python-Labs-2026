Quick Guide — Operators Used in This Lab

This lab uses several operators to convert minutes into hours and keep the final time within a normal 24-hour clock.

+ adds values.
// is integer (floor) division. It gives the number of complete groups. For example, 125 // 60 is 2 complete hours.
% is the modulus operator. It gives the remainder. For example, 125 % 60 is 5 remaining minutes.
= assigns a value to a variable.

Why // and % work well together: if you have 125 minutes, 125 // 60 gives 2 full hours and 125 % 60 gives the 5 minutes left over.

Lab Scenario

Your task is to write a Python program that calculates the end time of an event when you know its starting hour, starting minutes, and duration in minutes.

The duration can be large enough to move the ending time into the next day. Your program will correct both the minutes and hours so the final result is displayed using a 24-hour clock.

Task 1 — Input the Starting Time and Duration

Create Lab11.py. Ask the user for three integer values: starting hour, starting minutes, and event duration in minutes.

hour = int(input("Starting time (hours): ")) mins = int(input("Starting time (minutes): ")) dura = int(input("Event duration (minutes): "))

Why int()? input() receives text. int() converts that text into an integer so Python can perform arithmetic with it.

Task 2 — Add the Duration to the Minutes

Add the event duration to the starting minutes. This creates the total number of minutes that must be accounted for.

mins = mins + dura

For example, if the event starts at 12:17 and lasts 59 minutes, the temporary minute value becomes 17 + 59 = 76. Since 76 is greater than 59, some of those minutes must be converted into hours.

Task 3 — Convert Complete Minutes to Hours

Use integer division // to determine how many complete hours are contained in the total minutes. Add those hours to the starting hour.

hour = hour + mins // 60

Example: 76 // 60 equals 1, so one complete hour is added to the starting hour.

Task 4 — Correct the Minutes

Now use the modulus operator % to keep only the minutes left after complete hours have been removed.

mins = mins % 60

Example: 76 % 60 equals 16. The corrected minute value is therefore 16.

Task 5 — Correct the Hours

If the calculated hour goes past 23, the clock has moved into a new day. Use modulus % 24 to keep the hour in the valid 0–23 range.

hour = hour % 24

For example, an hour value of 25 becomes 25 % 24 = 1, which represents 1:00 on the next day.

Task 6 — Print and Test the End Time

Print the calculated hour and minutes separated by a colon. The sep='' argument prevents Python from inserting spaces between the values.

print(hour, ":", mins, sep='')
