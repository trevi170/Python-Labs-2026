Scenario

You are creating a simple secure-login simulator. The program stores the correct password as python123. The user gets up to three attempts. A correct password grants access immediately. Three failed attempts lock the account.

Quick Guide — Understand the Logic First

correct_password stores the password the user must match.

attempts counts failed password attempts and begins at 0.

while attempts < 3 means the program can keep asking while fewer than three failures have occurred.

break immediately exits the loop after a correct password.

Why while-else? The final else belongs to the while. It runs when the loop finishes normally after three failures. If break exits the loop after a correct password, Account locked. is skipped.

Task 6 — Check the password

If the password matches, grant access and break. If it is wrong, deny access and increase the failed-attempt counter.

if password == correct_password:
    print("Access granted.")
    break
else:
    print("Access denied. Try again.")
    attempts += 1
Important: attempts += 1 happens only when the password is wrong. A correct password uses break and ends the loop.

Task 7 — Add the while-else lockout

This else lines up with while. It runs only if the loop ends without break.

else:
    print("Account locked.")

Understanding the Indentation

while attempts < 3:
    password = input(...)

    if password == correct_password:
        print("Access granted.")
        break
    else:                         # belongs to IF
        print("Access denied. Try again.")
        attempts += 1
else:                             # belongs to WHILE
    print("Account locked.")

The final else must line up with while, not with if.

Complete Code — Review

# Extra Credit: Secure Login Simulator (Week 7 Loops)
# Uses: while loop, counter variable, break, while-else

correct_password = "python123"
attempts = 0

while attempts < 3:
    password = input("Enter your password: ")

    if password == correct_password:
        print("Access granted.")
        break
    else:
        print("Access denied. Try again.")
        attempts += 1
else:
    print("Account locked.")
