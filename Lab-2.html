Task 2

Modify the First print() Function with sep

The sep argument controls what Python places between multiple values passed to print().

Type This Change Manually

print("Programming", "Essentials", "in", sep="***") print("Python")

What Changed?

CodeExplanation
sep="***"Python places three asterisks between the three strings instead of its normal single space.
print("Python")This second line remains unchanged, as required by the lab.

Expected Result at This Point

Programming***Essentials***in Python
The words are now separated correctly, but Python is still on a new line. The next task fixes that by changing the end argument.
Task 3

Add the end Argument

The end argument controls what Python places at the end of a print() call. Normally, print() ends with a newline.

Modify Only the First Line

print("Programming", "Essentials", "in", sep="***", end="...") print("Python")

What This Does

ArgumentEffect
sep="***"Places *** between Programming, Essentials, and in.
end="..."Places three periods at the end of the first print() call instead of moving to a new line.

Expected Output

Programming***Essentials***in...Python
