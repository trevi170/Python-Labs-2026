Lab 32: Building a Triangle Validator Function

Write a function that checks whether three side lengths can form a triangle.

Each task adds to the same program. Screenshot checkpoints help you document your progress.

Learning Objectives

Write a function that checks whether three side lengths can form a triangle. Practice function calls, code indentation, and checking results.

TASK 1

Write the triangle function

Enter this complete function in the Python file you already opened.

def is_a_triangle(a, b, c):
    return a + b > c and b + c > a and c + a > b
Line-by-line and indentation guide

• 0 spaces: `def` starts at the left edge.

• 4 spaces: `return` belongs inside the function.

• `a`, `b`, and `c` are the three side lengths.

• All three comparisons must be True: the sum of any two sides must be greater than the third.

• `return` sends True or False back to the calling code.

TASK 2

Ask the user for three sides

Add these lines below the function, without indentation.

side1 = float(input("Enter the first side's length: "))
side2 = float(input("Enter the second side's length: "))
side3 = float(input("Enter the third side's length: "))
Line-by-line and indentation guide

• 0 spaces: All three input lines start at the left edge.

• `input()` reads what the user types. `float()` converts the text into a number.

• Each side is stored in its own variable.

TASK 3

Check and print the result

Add the condition below the input lines, then run the program twice: once with 3, 4, 5 and once with 1, 1, 3.

if is_a_triangle(side1, side2, side3):
    print("Yes, it can be a triangle.")
else:
    print("No, it can't be a triangle.")
Line-by-line and indentation guide

• 0 spaces: `if` and `else` must line up.

• 4 spaces: Each `print()` is indented inside its matching branch.

• The function returns True for 3, 4, 5; it returns False for 1, 1, 3.
