Task 1

Use Fewer print() Statements

The original program uses eight print() calls. Use \n to create a new line inside one string.

print(" *\n * *\n * *\n * *\n*** ***\n * *\n * *\n *****")
Code / SymbolWhat it does
print(Calls Python's built-in print function.
" ... "The quotation marks define a string of text.
\nMoves the next characters to a new output line.
)Closes the function call.

Expected Output

* * * * * * * *** *** * * * * *****
What you learned: The output looks the same, but the program now uses only one print() statement.

Task 3

Duplicate the Arrow Side by Side

String multiplication repeats a string. The extra spaces at the end of each row create a gap before the second arrow.

print((" * ") * 2) print((" * * ") * 2) print((" * * ") * 2) print((" * * ") * 2) print(("*** *** ") * 2) print((" * * ") * 2) print((" * * ") * 2) print((" ***** ") * 2)
Code / SymbolWhat it does
" * "Creates one row of the arrow plus spacing after it.
* 2Repeats that entire string two times.
print(...)Displays the repeated row.

Expected Output

* * * * * * * * * * * * * * *** *** *** *** * * * * * * * * ***** *****
Task 4

Remove Quotation Marks and Observe the Error

Start with this correct line:

print(" *")

Now intentionally remove the quotation marks:

print( *)
Expected result: Python should report a SyntaxError. The exact message can vary by Python version or editor.

After observing the error, repair the line:

print(" *")
Task 5

Remove Parentheses and Observe the Error

Correct Python 3 statement:

print(" *")

Intentionally change it to:

print " *"

In Python 3, print is a function, and function calls use parentheses.

Expected result: Python should report a SyntaxError, often mentioning missing parentheses.
Task 6

Change print to Print

Type this intentionally incorrect version:

Print(" *")

Python is case-sensitive. print and Print are different names.

Expected result: Python should report a NameError because Print is not defined.

Fix the line by using lowercase:

print(" *")
Task 7

Replace Double Quotes with Apostrophes

Change this:

print(" *")

to this:

print(' *')

Both single and double quotation marks can define a Python string.

Expected Output

*
What you learned: In this example, changing double quotes to single quotes does not change the output.

Additional Note — sep and end

The source lab notes that the print() function also supports formatting parameters such as sep and end. These are useful for controlling spacing between values and what happens at the end of printed output, but they are not one of the seven required modification tasks in this lab.
