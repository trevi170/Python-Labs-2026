Objectives

Practice float()/int() input, comparisons, and, or, not, if/elif/else, and conditional logic.

Quick Guide

== != < <= > >= compare values. and requires both conditions to be true. or requires at least one. not reverses a Boolean condition.

Scenario

Build a Campus Store checkout system that collects shopper information, applies the correct discount, calculates subtotal, discount amount, tax, and final total, and prints a clean receipt.

Discount Priority — Only ONE Discount

  1. Age ≥ 60 → 15% off
  2. Student = "yes" and subtotal ≥ $25 → 10% off
  3. Coupon = "yes" and subtotal ≥ $40 → $5 off
  4. Otherwise → no discount

Tax Rules

Student = "yes" → 6%. Otherwise → 8%.

Task 1 — Create Your File and Print a Title

Create lab_campus_store.py. Print a title for the checkout program, run it, and verify the title appears.

Task 2 — Collect All Inputs

Ask for the five required inputs. Use int() for age and float() for subtotal.

name = input("Enter your name: ")
is_student = input("Are you a student? (yes/no): ")
age = int(input("Enter your age: "))
subtotal = float(input("Enter your subtotal: "))
has_coupon = input("Do you have a coupon? (yes/no): ")

Task 3 — Set Up Variables

Give the discount variables starting values.

discount_type = "None"
discount_amount = 0.0

Task 4 — Choose Which ONE Discount Applies

Use the required priority order. The if/elif/else structure prevents discounts from stacking.

if age >= 60:
    discount_type = "Senior (15%)"
    discount_amount = subtotal * 0.15
elif is_student == "yes" and subtotal >= 25:
    discount_type = "Student (10%)"
    discount_amount = subtotal * 0.10
elif has_coupon == "yes" and subtotal >= 40:
    discount_type = "Coupon ($5)"
    discount_amount = 5.0
else:
    discount_type = "None"
    discount_amount = 0.0

Task 5 — Calculate the Discounted Subtotal

Subtract the discount from the original subtotal.

new_subtotal = subtotal - discount_amount

Task 6 — Choose the Tax Rate

Students use 6%; everyone else uses 8%.

if is_student == "yes":
    tax_rate = 0.06
else:
    tax_rate = 0.08

Task 7 — Calculate Tax and Final Total

Calculate tax from the discounted subtotal, then calculate the final total.

tax = new_subtotal * tax_rate
total = new_subtotal + tax

Task 8 — Print a Clean Receipt

Display the customer's name, subtotal, discount type, discount amount, tax, and final total.

print("\nRECEIPT")
print("----------------------")
print("Customer: " + name)
print("Subtotal: $" + str(subtotal))
print("Discount: " + discount_type)
print("Discount Amount: $" + str(discount_amount))
print("Tax: $" + str(tax))
print("Total: $" + str(total))
print("----------------------")
print("Thank you!")
