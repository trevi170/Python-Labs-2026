Lab Scenario

Your task is to complete a Python program that asks the user for two floating-point values. The program will use those values to perform four basic arithmetic operations: addition, subtraction, multiplication, and division. The results will then be displayed in the console with clear labels.

Why this matters: Most useful programs need to accept information from a user, process that information, and display a result. This lab practices that basic input → processing → output pattern.

Task 1 — Input Two Float Values

Create Lab9.py. Ask the user to enter two values and store them in variables named a and b.

a = float(input("Enter the first number: ")) b = float(input("Enter the second number: "))

What is happening? input() collects what the user types. float() converts that input into a floating-point number so Python can perform arithmetic with it. For example, the user can enter 5, -2, or 3.75.

Task 2 — Perform the Arithmetic Operations

Use a and b in four expressions. Each operator tells Python which calculation to perform.

addition = a + b subtraction = a - b multiplication = a * b division = a / b

Operator reminder: + adds, - subtracts, * multiplies, and / divides. The value calculated on the right side of = is stored in the variable on the left side.

Division note: Do not use 0 as the second value (b) when testing division. Dividing by zero causes a Python error.

Task 3 — Print the Results

Display each result with a descriptive label so someone reading the output knows which calculation was performed.

print("Addition:", addition) print("Subtraction:", subtraction) print("Multiplication:", multiplication) print("Division:", division)

The first argument to print() is descriptive text. The second argument is the variable containing the calculated result. Python displays them together on the same line.

Task 4 — Test the Program with Different Values

Run the complete program several times. Test different kinds of numbers so you can observe how the calculations change.

Try at least one set of positive values, one set containing a negative value, and one set containing decimal values. Remember that b cannot be zero because the program divides by b.

Example test ideas: 8 and 2; -6 and 3; 7.5 and 2.5. You may use different values.

Task 5 — Finish the Program

After the arithmetic results have been printed, add the final message required by the lab.

print("\nThat's all, folks!")

The \n is a newline character. It creates a blank line before the final message, making the output easier to read. Run the entire program one final time and verify that all four calculations and the closing message appear.
