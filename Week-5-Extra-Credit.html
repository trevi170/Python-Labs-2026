Week 5 • Extra Credit

Student Utility Console

Python practice using GitHub Codespaces

Objective

Build a small Python program that collects information from a user, converts numeric input, performs a percentage calculation, uses string replication, and prints a clean student summary.

Editor of choice: GitHub Codespaces. You will write and run your program entirely in the browser.

Before You Begin

What you will practice: print(), variables, input(), float(), int(), arithmetic operators, string replication, concatenation, and str().

Step 1 — Open GitHub Codespaces

  1. Sign in to GitHub.
  2. Open the Codespace provided for your course, or create a Codespace from the repository your instructor provides.
  3. Wait for the Codespaces editor to finish loading.
  4. In the Explorer panel, create a new file named extra_credit.py.
  5. Open the new file in the editor.

Check Python

Open the terminal in Codespaces and type:

python3 --version
If a Python version appears, you are ready to continue.

Step 2 — Add a Title

At the top of extra_credit.py, type:

print("Extra Credit Project")
print("====================")

This gives your program a clear title when it runs.

Step 3 — Collect User Input

Use input() to ask the user for information. Enter:

student_name = input("Enter student name: ")
course_name = input("Enter course name: ")
assignment_name = input("Enter assignment name: ")

score_earned = float(input("Enter score earned: "))
score_total = float(input("Enter maximum possible score: "))

repeat_count = int(input("How many times should the separator repeat? "))
Why convert the numbers? input() returns text. float() converts scores to numbers that can include decimals, while int() converts the separator count to a whole number.

Step 4 — Create a Separator

String replication lets Python repeat text using the * operator.

line = "=" * repeat_count

Step 5 — Calculate the Percentage

percentage = (score_earned / score_total) * 100
Operator review: / divides the score earned by the total possible score. * multiplies that result by 100 to convert it to a percentage.

Step 6 — Print the Results

Use concatenation with + and str() to display the results.

print(line)
print("Student Summary")
print(line)

print("Name: " + student_name)
print("Course: " + course_name)
print("Assignment: " + assignment_name)

print("Score: " + str(score_earned) + " out of " + str(score_total))
print("Percentage: " + str(percentage) + " %")

print(line)
print("Great job, " + student_name + "!")
print(line)
str() converts a number back to text so it can be joined to other text with +.
