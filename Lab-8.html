Quick Guide — What is a comment?
A comment is a note written inside a Python program for people to read. Python ignores comments when the program runs. A comment begins with the # symbol.

# This is a comment
hours = 2 # This is also a comment
Important: If # is placed in front of a line of Python code, that entire line becomes a comment and Python will not run it. Removing the # makes that line active again.

Lab Scenario

The starter program contains several Python comments. Your job is to improve the program by deciding which comments are useful, which can be removed, and which commented-out code should be activated.

Key idea: A Python comment begins with #. Python ignores everything after the # on that line. Comments should help explain code when needed, but readable code and meaningful variable names can often explain themselves.

Task 1 — Create the Starter Program

Create Lab8.py and manually type the starter program shown below. Do not change anything yet. The purpose of this first step is to see which lines Python runs and which lines it ignores.

# this program computes the number of seconds in a given number of hours # this program has been written two days ago a = 2 # number of hours seconds = 3600 # number of seconds in 1 hour print("Hours: ", a) # printing the number of hours # print("Seconds in Hours: ", a * seconds) # printing the number of seconds in a given number of hours # here we should also print "Goodbye", but a programmer didn't have time to write any code # this is the end of the program that computes the number of seconds in 3 hour

What to notice: Lines beginning with # are comments, so Python skips them. The line that prints the seconds also begins with #, so it will not run yet.

Run the program once before making changes. At this point, you should see the hours printed, but you should not see the seconds or the word Goodbye.

Task 2 — Identify Useful and Unnecessary Comments

Now examine the comments in the starter program. A good comment should provide useful information. Some comments in this program are unnecessary, outdated, or incorrect on purpose.

Your job: read each comment and ask, “Does this comment help me understand the program?” If the answer is no, remove it or improve it.

For example, # this program has been written two days ago does not help explain how the program works, so it can be removed. Also notice that the final comment says 3 hour even though the variable currently contains 2. That comment is outdated and should not be trusted just because it is written in the program.

Remember: Good comments explain why something is being done or provide useful context. Comments do not need to repeat exactly what a clear line of code already says.

Task 3 — Enable Commented-Out Code

Comments can also be used temporarily to prevent a line of code from running. Find the line below. Because it starts with #, Python ignores the entire line even though it contains a valid print() statement.

# print("Seconds in Hours: ", a * seconds)

Remove only the first # so the line becomes active Python code. Do not delete the print() statement. Run the program again.

The expression a * seconds means 2 × 3600. Python calculates the result and prints 7200. This demonstrates the difference between a commented-out line and an active line of code.

With a = 2 and seconds = 3600, the calculation should produce: 7200

Task 4 — Improve Variable Names

The variable a stores the number of hours, but the name a does not tell the reader what the value represents. Clear variable names can make code understandable without needing extra comments.

Rename a to hours. This is called using a descriptive variable name.

hours = 2 seconds = 3600

Important: After changing a to hours, change it everywhere it is used, including both print() statements. If one old a remains, the program may produce an error. Run the program and confirm that the results are still 2 hours and 7200 seconds.

Task 5 — Add the Missing Goodbye Message

One comment describes something the programmer wanted the program to do: print the word Goodbye. A comment only describes an idea; it does not make Python perform that action.

Replace the comment about printing Goodbye with a real Python print() statement.

print("Goodbye")

Run the program again. Because print("Goodbye") is real code and does not begin with #, Python should now display Goodbye at the end.

Task 6 — Review and Clean Up the Program

For the final step, clean up the entire program. The goal is not to remove every comment. The goal is to keep comments only when they add useful information and let clear Python code explain the rest.

Make sure you use hours instead of a, the seconds line is active, the Goodbye statement is real code, and outdated comments are removed or corrected.

Your final output should include:
Hours: 2
Seconds in Hours: 7200
Goodbye
