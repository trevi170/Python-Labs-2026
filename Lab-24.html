Quick Guide — Understanding List Changes

Empty list: Beatles = [] creates a list with no members.

append(value): adds a new item to the end of a list.

for i in range(2): repeats the indented statements two times. Here it asks for two names.

del Beatles[-1]: deletes the last item. Repeating it twice deletes the two most recently added members.

insert(0, value): places an item at the beginning, shifting the existing members to the right.

len(Beatles): returns the total number of members in the list.

Important: Python is case-sensitive. Use Beatles consistently, with a capital B, as in the guide.

Scenario

The Beatles went through lineup changes before the familiar four-member configuration. You will simulate the changes using a Python list: begin with John Lennon, Paul McCartney, and George Harrison; temporarily add Stu Sutcliffe and Pete Best; remove the temporary members; then insert Ringo Starr at the beginning.

Task 2 — Add Three Initial Members

Use append() three times. Each call adds one name to the end of the list. The list now contains John Lennon, Paul McCartney, and George Harrison, in that order.

# step 2:
Beatles.append("John Lennon")
Beatles.append("Paul McCartney")
Beatles.append("George Harrison")
print("Step 2:", Beatles)

Task 3 — Add Two Temporary Members

Use for i in range(2) to repeat the indented input statement exactly twice. Enter Stu Sutcliffe first and Pete Best second when prompted. append(input(...)) adds each entered name to the end of the list.

# step 3:
for i in range(2):
    Beatles.append(input("New band member: "))
print("Step 3:", Beatles)

Task 4 — Remove the Temporary Members

The index -1 means the last list element. The first del Beatles[-1] removes Pete Best; the second removes Stu Sutcliffe. After both deletions, only the original three names remain.

# step 4:
del Beatles[-1]
del Beatles[-1]
print("Step 4:", Beatles)

Task 5 — Insert Ringo Starr at the Beginning

Use insert(0, "Ringo Starr"). Unlike append(), which adds at the end, insert() lets you choose the position. Index 0 is the beginning of the list.

# step 5:
Beatles.insert(0, "Ringo Starr")
print("Step 5:", Beatles)

Task 6 — Count and Test the Final Members

Add the final len() statement from the complete guide, then run the entire program. After adding Ringo Starr, the list contains four names, so the final line should say The Fab: 4.

# Testing the list length
