Task 3 — Create day_of_year

def day_of_year(year, month, day):
    md = days_in_month(year, month)
    if md is None or day < 1 or day > md:
        return None
    total = day
    for m in range(1, month):
        total += days_in_month(year, m)
    return total
NEW FOR LAB 28 — write this function yourself. Add it below both reused functions in Lab28.py.

Line 1 (0 spaces): Defines day_of_year with three inputs: year, month, and day.
Line 2 (4 spaces): Calls your Lab 27 function to find how many days are allowed in the chosen month. md means month days.
Line 3 (4 spaces): Checks for an invalid year/month (md is None), a day below 1, or a day beyond the month's length.
Line 4 (8 spaces): Stops and returns None for an invalid date.
Line 5 (4 spaces): Starts the total at the day number. For March 5, the starting total is 5.
Line 6 (4 spaces): range(1, month) visits earlier months only. For March, it visits January (1) and February (2), not March.
Line 7 (8 spaces): Adds the days in each earlier month to total using your Lab 27 function. += means “add to the current total.”
Line 8 (4 spaces): Returns the final day number in the year.

Example: March 5, 2023 → start at 5 + January's 31 + February's 28 = 64.
