Objectives

  • Calculate a date’s position within its year by adding earlier months.
  • Return None for invalid dates and test six cases.

Quick Guide

Parameters: year, month, and day identify one calendar date.

Accumulator: days = 0 starts a running total. days += md adds the length of an earlier month.

range(1, month): starts at January (1) and stops before the requested month. For March, it produces 1 and 2.

Reuse: days_in_month(year, m) handles February’s leap-year adjustment through is_year_leap().

Return value: return days + day adds the days from earlier months to the day of the current month; None means an invalid date.

Example: March 1, 2020 → January (31) + February (29) + March day (1) = 61. The year 2020 is a leap year.

Scenario

You are creating a calendar helper. January 1 is day 1 of the year. December 31 is day 365 in an ordinary year and day 366 in a leap year. The program must reject invalid dates, such as April 31 or a year before 1582.

Plan: Reuse earlier functions → add days in preceding months → validate the current day → return the total.

Indentation Quick Reference — Read Before Coding

Python uses indentation (spaces at the start of a line) to show which statements belong together. In this lab, each level is 4 spaces. Use spaces consistently; avoid mixing tabs and spaces.

def example(): # 0 spaces: function starts at left edge if True: # 4 spaces: inside function print("Hello") # 8 spaces: inside if print("Done") # 4 spaces: still in function, outside if print("Outside") # 0 spaces: outside function

How to align: Statements that belong to the same block start in the same column. A colon (:) usually starts a new indented block. To exit a block, remove 4 spaces (dedent). The code examples in every task show the exact leading spaces to use.

Code to type:

def is_year_leap(year):
    if year % 4 != 0:
        return False
    elif year % 100 != 0:
        return True
    elif year % 400 != 0:
        return False
    else:
        return True

What each line does

  1. def is_year_leap(year): — Defines a function that receives a year.
  2. if year % 4 != 0: — Checks whether the year is not divisible by 4; % gives the remainder.
  3. return False (first) — Returns False for a year that is not divisible by 4.
  4. elif year % 100 != 0: — If divisible by 4 but not by 100, the year is a leap year.
  5. return True (second branch) — Returns True for those leap years.
  6. elif year % 400 != 0: — For a century year, checks whether it is not divisible by 400.
  7. return False (third branch) — Rejects century years such as 1900.
  8. else: — Handles the remaining case: divisible by 400.
  9. return True (last) — Accepts century leap years such as 2000.

Task 2 — Reuse days_in_month()

Below the first function, type the function from Lab 27. Notice days[month - 1]: January is month 1 but Python index 0. This function already adjusts February for leap years.

Indentation and alignment — where to place each line

Place this def at the left margin, aligned with def is_year_leap. Its normal body lines use 4 spaces. Statements inside if blocks use 8 spaces. After return None, move back to 4 spaces for the days list.

Code to type:

def days_in_month(year, month):
    if year < 1582 or month < 1 or month > 12:
        return None
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    res = days[month - 1]
    if month == 2 and is_year_leap(year):
        res = 29
    return res

What each line does

  1. def days_in_month(year, month): — Creates a function with two inputs: year and month.
  2. if year < 1582 or month < 1 or month > 12: — Rejects years before 1582 and months outside 1–12; or means any one invalid condition is enough.
  3. return None — Stops the function when the year or month is invalid.
  4. days = [31, 28, ...] — Stores the usual number of days for January through December.
  5. res = days[month - 1] — Looks up the month’s days. Subtract 1 because January is month 1 but list index 0.
  6. if month == 2 and is_year_leap(year): — Checks whether it is February AND the year is a leap year.
  7. res = 29 — Changes February from 28 to 29 days for leap years.
  8. return res — Returns the final number of days in that month.

Task 6 — Validate the current day and return the result

After the loop, find the length of the selected month. A valid day must be at least 1 and no greater than md. For a valid date, return the total from earlier months plus the current day; otherwise return None. Keep the indentation shown.

Understanding the Calculation

For day_of_year(2020, 2, 29), the loop adds January’s 31 days. February 2020 has 29 days, so the day value 29 is valid. The function returns 31 + 29 = 60.

For day_of_year(2023, 4, 31), April has only 30 days. The condition day <= md fails, so the function returns None.

Important: The complete code in the uploaded guide directly compares day <= md. For a year before 1582 and a month greater than 1, the loop returns None before reaching that comparison. In this lab, follow the supplied code and test cases.

def is_year_leap(year):
    if year % 4 != 0:
        return False
    elif year % 100 != 0:
        return True
    elif year % 400 != 0:
        return False
    else:
        return True

def days_in_month(year, month):
    if year < 1582 or month < 1 or month > 12:
        return None
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    res = days[month - 1]
    if month == 2 and is_year_leap(year):
        res = 29
    return res

def day_of_year(year, month, day):
    days = 0
    for m in range(1, month):
        md = days_in_month(year, m)
        if md == None:
            return None
        days += md
    md = days_in_month(year, month)
    if day >= 1 and day <= md:
        return days + day
    else:
        return None
