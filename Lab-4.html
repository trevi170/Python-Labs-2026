LineWhat to Notice

Task 2

Practice Displaying Quotation Marks

Quotation marks normally mark the beginning and end of a Python string. To display a double quotation mark as part of the output, place a backslash before it.

Type This Code Manually

print("\"I'm\"")

What Each Part Means

CodeExplanation
\"The backslash escapes the double quote, telling Python to display the quotation mark instead of treating it as the end of the string.
I'mThe apostrophe is part of the text. Because the surrounding Python string uses double quotes, the apostrophe does not end the string.
print(...)Displays the completed string.

Expected Output

"I'm"
Task 3

Use \n to Create New Lines

The newline escape sequence \n moves the following output to the next line without requiring another print() statement.

Type This Code Manually

print("\"I'm\"\n\"\"learning\"\"")
CodeExplanation
\nEnds the first output line and moves the next characters to a new line.
\"\"Two escaped double quotes are displayed before and after learning.

Expected Output

"I'm" ""learning""
Task 4

Create the Complete Output with One print()

Now combine the escape characters and newline characters into one Python statement.

Type This Final Code Manually

print("\"I'm\"\n\"\"learning\"\"\n\"\"\"Python\"\"\"")

How the Final Line Works

PartPurpose
\"I'm\"Produces the first line with one double quote on each side.
\nMoves to the second line.
\"\"learning\"\"Produces the second line with two double quotes on each side.
\nMoves to the third line.
\"\"\"Python\"\"\"Produces the third line with three double quotes on each side.

Expected Output

"I'm" ""learning"" """Python"""
