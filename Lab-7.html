Lab Scenario

Your goal is to evaluate the algebraic expression below for different values of x:

y = 3x³ - 2x² + 3x - 1

Python cannot read algebraic notation exactly the way it appears in a math class. You must translate the expression into Python syntax before the computer can calculate it.

Quick Guide:
= assigns a value to a variable.
* means multiplication.
** means exponentiation (raising a value to a power).
+ and - perform addition and subtraction.
Python follows the normal order of operations, so exponents are evaluated before multiplication, addition, and subtraction.

Task 1 — Assign a Value to x

Start by assigning one of the required test values to x. A variable is a name that stores a value so the program can use it later in a calculation.

x = 0

You will later repeat the test using x = 1 and x = -1.

Task 2 — Convert x to a Float

Use the float() function so that x is stored as a floating-point number. A float is a number that can include a decimal point.

x = float(x)

Explanation: This converts values such as 0 into 0.0. Using a float makes it easy to test decimal values such as 2.5 later in the lab.

Task 3 — Evaluate the Expression

Translate the algebraic expression into valid Python syntax. The mathematical expression you are converting is:

y = 3x³ - 2x² + 3x - 1

Now write the same expression using Python operators:

y = 3 * x ** 3 - 2 * x ** 2 + 3 * x - 1

Explanation: In mathematics, 3x³ means 3 times x cubed. In Python, that must be written as 3 * x ** 3. Likewise, 2x² becomes 2 * x ** 2. The ** operator performs exponentiation, while * performs multiplication.

Order of operations: Python calculates the powers first, then multiplication, and finally addition and subtraction from left to right.

Task 4 — Print the Result

Display the calculated value of y. The print() function lets you see the result that Python stored in the variable.

print("y =", y)
Expected format: y = RESULT

Task 5 — Test the Required Values

Run the program three times using these values. Each time you change x, Python recalculates y using the same expression.

x = 0 x = 1 x = -1
Expected results: For x = 0, y = -1.0 For x = 1, y = 3.0 For x = -1, y = -9.0

Change only the value assigned to x between runs.

Try additional positive and negative values, including decimal values. This helps you observe how changing the input value x changes the output value y.
