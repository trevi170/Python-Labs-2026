Task 1

Print a String

Use the print() function to display Hello, Python!.

Step 1 — Open Python

Open your Python environment or text editor and create a new Python file.

Step 2 — Type This Code Manually

print("Hello, Python!")

What the Line Does

PartExplanation
printCalls Python's built-in output function.
( )The parentheses contain the value being sent to the function.
"Hello, Python!"The quotation marks identify the characters as text, or a string.

Step 3 — Run the Program

Run the program and compare your result to the expected output.

Expected Output

Hello, Python!
Task 2

Print Your First Name

Use print() to display your first name. Make sure your name is inside double quotation marks.

Step 1 — Type the Pattern

print("YourFirstName")

Replace YourFirstName with your actual first name.

Example

print("Maria")

Expected Output

Your output should display your own first name. Example:

Maria
What you are learning: Text must be placed inside quotation marks so Python recognizes it as a string.
Task 3

Remove the Double Quotes

Now intentionally remove the double quotation marks from around your first name and run the program.

Correct Version

print("YourFirstName")

Type the Incorrect Version

Example using the name Maria:

print(Maria)

Run the Program

Expected Result: Python will normally report a NameError because it now treats the name as an identifier instead of text. The exact wording may vary by Python version.

Example Error

NameError: name 'Maria' is not defined

Fix the Error

Put the quotation marks back around your name and run the program again.

print("YourFirstName")
Task 4

Remove the Parentheses

Put the quotation marks back around your first name, but remove the parentheses from the print() function.

Correct Version

print("YourFirstName")

Type the Incorrect Version

print"YourFirstName"

Run the Program

Expected Result: Python should report a SyntaxError. The exact message may vary by Python version or editor.

In Python 3, print is a function, and function calls require parentheses.

Fix the Error

print("YourFirstName")
