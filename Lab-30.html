Objectives

  • Define functions with parameters and return values.
  • Convert liters per 100 km (L/100 km) to US miles per gallon (mpg).
  • Convert mpg to L/100 km.
  • Run the six tests from the supplied Lab 30 guide.

Quick Guide

L/100 km: Liters of fuel consumed to travel 100 kilometers. mpg: Miles traveled using one US gallon of fuel.

Conversion constants: 1 mile = 1609.344 meters; 1 US gallon = 3.785411784 liters.

Operators: / means division, * means multiplication. return sends a calculated value back to the caller; print() displays it.

Important: A smaller L/100 km value means less fuel used. A larger mpg value means more distance per gallon. The supplied examples use positive inputs; the guide does not add zero/negative-input handling.

Scenario

Fuel consumption is measured in different units in Europe and the United States. Write one function for each direction of conversion, then compare your results with the six values provided in the lab guide.

Indentation Quick Reference — Read Before Coding

Python uses 4 spaces per indentation level. A function definition starts at 0 spaces; all its statements begin at 4 spaces. Test calls written outside the functions begin at 0 spaces.

def example(value):        # 0 spaces
    result = value * 2     # 4 spaces
    return result         # 4 spaces

print(example(3))          # 0 spaces

When you finish a function, remove its four-space indentation before starting another def or a test print().

# 1 American mile = 1609.344 metres
# 1 American gallon = 3.785411784 litres

def liters_100km_to_miles_gallon(litres):
    # Convert liters to gallons
    gallons = litres / 3.785411784
    # Convert 100 kilometers to miles
    miles = 100 * 1000 / 1609.344
    # Calculate miles per gallon
    return miles / gallons

def miles_gallon_to_liters_100km(miles):
    # Convert miles to kilometers per 100 km
    km100 = miles * 1609.344 / 1000 / 100
    # Convert gallons to liters
    litres = 3.785411784
    # Calculate liters per 100 kilometers
    return litres / km100
