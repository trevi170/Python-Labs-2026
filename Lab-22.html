What Is Collatz's Hypothesis?

The original lab explains that German mathematician Lothar Collatz formulated this hypothesis in 1937 and that it remains unproven. For this exercise, you will use Python to test individual starting numbers.

Start with a positive, non-zero integer called c0. Then follow these rules:

  1. If c0 is even, calculate c0 ÷ 2.
  2. If c0 is odd, calculate 3 × c0 + 1.
  3. Make the result the new c0.
  4. If c0 is not 1, repeat the process.

The hypothesis says this process eventually reaches 1 for any positive starting value. This lab is about implementing and observing the process, not proving the hypothesis.

Follow the Process Before You Code

Here is a practice example using c0 = 6. At each step, decide whether the current value is odd or even.

Start: c0 = 6

6  → EVEN → 6 // 2       = 3
3  → ODD  → 3 * 3 + 1   = 10
10 → EVEN → 10 // 2      = 5
5  → ODD  → 3 * 5 + 1   = 16
16 → EVEN → 16 // 2      = 8
8  → EVEN → 8 // 2       = 4
4  → EVEN → 4 // 2       = 2
2  → EVEN → 2 // 2       = 1

STOP — c0 has reached 1.

The key idea: every answer becomes the next value of c0. In Python, c0 = cnew performs that update.

From the Math Rule to Python

Is the current value odd?
if c0 % 2 != 0:

Odd rule:
cnew = 3 * c0 + 1

Even rule:
cnew = c0 // 2

Use the answer for the next loop:
c0 = cnew

Keep repeating until 1:
while c0 != 1:

Quick Guide — Understanding the Collatz Rules

Big picture: Think of c0 as the current number. The program decides whether it is odd or even, calculates the next number, makes that answer the next c0, and repeats until c0 becomes 1.

If the number is odd: calculate 3 * c0 + 1.

If the number is even: calculate c0 // 2.

Repeat these calculations while c0 != 1.

% — remainder operator: c0 % 2 != 0 means there is a remainder when dividing by 2, so the value is odd.

// — integer division: c0 // 2 divides by 2 and produces an integer result.

cnew: temporarily stores the next value before it replaces c0.

steps: counts each update made while working toward 1.

Walk-Through Example — Start with 6

6 is even  → 6 // 2 = 3
3 is odd   → 3 * 3 + 1 = 10
10 is even → 10 // 2 = 5
5 is odd   → 3 * 5 + 1 = 16
16 is even → 16 // 2 = 8
8 is even  → 8 // 2 = 4
4 is even  → 4 // 2 = 2
2 is even  → 2 // 2 = 1

Now c0 is 1, so the while loop stops.

Task 5 — Determine Whether c0 Is Odd or Even

Decide which Collatz rule to use. c0 % 2 checks the remainder after division by 2. A nonzero remainder means odd, so calculate 3 * c0 + 1. Otherwise it is even, so calculate c0 // 2. Store the answer temporarily in cnew.

Code:

if c0 % 2 != 0:
    cnew = 3 * c0 + 1
else:
    cnew = c0 // 2

Collatz rule: An odd value uses 3 * c0 + 1. An even value uses integer division c0 // 2.

Understanding the Indentation

This program has an outer if, a while loop, and another if/else inside the loop. Indentation tells Python which statements belong together.

if c0 > 1:                 # outer decision
    steps = 0
    while c0 != 1:         # repeat until c0 becomes 1
        if c0 % 2 != 0:    # odd/even decision
            ...
        else:
            ...
        print(c0)
        c0 = cnew           # next current number
        steps += 1          # count this calculation
    print("steps =", steps) # after the while loop
else:
    print("Bad c0 value")

Common mistake: c0 = cnew and steps += 1 must stay inside the while loop because both need to happen during every iteration.
