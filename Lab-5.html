Scenario

John, Mary, and Adam have some apples. John has 3 apples, Mary has 5 apples, and Adam has 6 apples. Your job is to create variables that store the number of apples each person has, display their values, and calculate the total number of apples.

As you work through the lab, you will also experiment with basic arithmetic operators and practice displaying text together with numeric values.

Task 1 — Create Variables

Create three integer variables named john, mary, and adam.

john = 3 mary = 5 adam = 6

Use the values from the scenario: John has 3 apples, Mary has 5 apples, and Adam has 6 apples.

Task 2 — Print the Variables

Print all three values on the same line and separate them with commas.

print(john, mary, adam, sep=",")
Expected format:
3,5,6

Task 3 — Create a Total Variable

Create total_apples and store the sum of all three variables.

total_apples = john + mary + adam

The + operator adds the integer values and stores the result in total_apples.

Task 4 — Print the Total

Print the total, then practice displaying a string and an integer variable together.

print(total_apples) print("Total number of apples:", total_apples)
Expected format:
Total number of apples: 14

Task 5 — Experiment with Your Code

Create new variables with different values and experiment with addition, subtraction, multiplication, division, and integer division.

a = 10 b = 3 print(a + b) print(a - b) print(a * b) print(a / b) print(a // b)

Observe the results, especially the difference between / and //. Also practice printing strings and integer variables on the same line.
