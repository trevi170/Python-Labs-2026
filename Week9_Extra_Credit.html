Objectives

Use Python lists to organize repeated student scores, keep unique values, add and remove elements, and report the length of the resulting list.

Quick Guide

List: a collection of values written inside square brackets, such as [85, 92, 85].

for score in scores: processes each item in order.

not in: tests whether a value has not yet been added.

append(95): adds 95 at the end. insert(0, 78): adds 78 at the beginning (index 0).

del unique_scores[-1]: deletes the last element. len(...): counts how many elements remain.

Remember: Python uses indentation to show which statements belong inside the for loop and if condition.

Scenario

You help a school office clean up a list of student assessment scores. Some scores appear more than once. Your job is to build a new list containing each score only once, then make a few updates requested by the office. Preserve the order of the first appearance of each score.

Follow the duplicate removal

Original: [85, 92, 85, 70, 92, 100, 70, 88]
Unique:   [85, 92, 70, 100, 88]

Later, you will append 95, insert 78 at the beginning, and delete the last entry.

Complete Code — Review After Finishing

scores = [85, 92, 85, 70, 92, 100, 70, 88]
print("Original scores:", scores)

unique_scores = []
for score in scores:
    if score not in unique_scores:
        unique_scores.append(score)

unique_scores.append(95)
unique_scores.insert(0, 78)
del unique_scores[-1]

print("Final unique scores:", unique_scores)
print("Number of unique scores:", len(unique_scores))
