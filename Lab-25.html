Quick Guide

A list stores several values in one variable. For example, [1, 2, 4] contains three numbers. List positions start at index 0, although this program uses a for loop rather than accessing individual positions.

for number in my_list: reads each element of the original list in order.

number in new_list is true if the number is already present. number not in new_list is true only if it has not been added yet.

new_list.append(number) adds the number to the end of the new list.

Key idea: We are not deleting items from my_list. We create a second list that keeps only the first occurrence of each number.

Scenario

You have a list of numbers that contains repetitions. Write a program that creates another list in which every number appears only once, while preserving the order of its first appearance.

Task 4 — Check for duplicates and add unique numbers

Inside the loop, use if number not in new_list:. This checks whether the current number is absent from the new list. Only when it is absent should append(number) add it. Indent the if under the for, and append() under the if.

Code / filename:

for number in my_list:
    if number not in new_list:
        new_list.append(number)
Why it works: The first time 4 is checked, it is missing, so it is appended. When 4 appears again, 4 not in new_list is false, so the append line is skipped.

Understanding the Indentation

for number in my_list:             # Repeat for every original number
    if number not in new_list:     # Only when number is new
        new_list.append(number)    # Add that number

print("The list with unique elements only:", new_list)

The if is inside the for loop, and append() is inside the if. The final print belongs outside both blocks.
