Task 2 — Write the new days-in-month function

This is NEW code for Lab 27. Keep the is_year_leap(year) function you copied from Lab26.py at the top. Leave one blank line after it, then type the function below in the same Lab27.py file. Do not copy the Lab 26 test statements.

def days_in_month(year, month):
    if year < 1582 or month < 1 or month > 12:
        return None
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if month == 2 and is_year_leap(year):
        return 29
    return days[month - 1]
How to indent: Start def at the far left (0 spaces). Put both if lines, days =, and the final return days[...] at 4 spaces. Put return None and return 29 at 8 spaces because each belongs inside an if. The last return moves back left to 4 spaces: it is outside both if blocks.

What each line does:

  1. def days_in_month(year, month): creates a new function. year and month are the two inputs.
  2. if year < 1582 or month < 1 or month > 12: checks for an invalid year or month. or means any one invalid condition is enough.
  3. return None stops the function when the input is invalid. None means there is no valid answer.
  4. days = [...] stores the normal number of days for January through December, in order. February starts at 28.
  5. if month == 2 and is_year_leap(year): checks whether the month is February and the year is a leap year. is_year_leap() is the function reused from Lab 26.
  6. return 29 gives February 29 days when both conditions are true.
  7. return days[month - 1] finds the number of days for other months. We subtract 1 because January is month 1 but list index 0. For example, month = 1 gives days[0] = 31; month = 2 gives days[1] = 28.
Walkthrough: days_in_month(2000, 2) returns 29 because 2000 is a leap year. days_in_month(2023, 2) returns 28. days_in_month(2023, 13) returns None because month 13 is invalid.
