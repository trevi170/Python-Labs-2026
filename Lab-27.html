Quick Guide

Function parameters: year and month are values supplied when the function is called.

return: sends a result back to the calling code. return None indicates an invalid input.

List indexing: list positions begin at 0, but months begin at 1. That is why we use days[month - 1].

and: both conditions must be true. February needs 29 days only when month == 2 and is_year_leap(year).

Function reuse: days_in_month() calls is_year_leap() instead of repeating leap-year rules.

Example: January is month 1, so days[1 - 1] accesses index 0, which contains 31. February is month 2, so days[2 - 1] accesses index 1, which initially contains 28.

Scenario

You are writing a calendar helper. Given a year and a month, the program must return the correct number of days. February is special: it has 29 days in a leap year, otherwise 28. Invalid months (outside 1–12) or years before 1582 must return None.

Decision sequence: Validate input → find normal month length in a list → adjust February if leap year → return the answer.

Indentation Quick Reference — Read Before Coding

Python uses 4 spaces per indentation level. A line ending in a colon (:) starts a block; the following line must be indented 4 more spaces. Statements in the same block must line up. To leave a block, move back 4 spaces (dedent). Do not mix tabs and spaces.

def example():          # 0 spaces
    if True:           # 4 spaces
        print("Hi")    # 8 spaces
    print("Done")       # 4 spaces
print("Outside")        # 0 spaces

Task 1 — Reuse the leap-year function

Begin by adding the is_year_leap(year) function from Lab 26. It returns True for leap years and False otherwise. The new function will call it when checking February.

Indentation and alignment — exactly where to type

Place def at 0 spaces. The if, elif, and else lines all have 4 spaces. Every return inside a condition has 8 spaces.

def is_year_leap(year):
    if year % 4 != 0:
        return False
    elif year % 100 != 0:
        return True
    elif year % 400 != 0:
        return False
    else:
        return True

What each line does

  1. def is_year_leap(year): — Defines a reusable function. The parameter year receives the year being tested.
  2. if year % 4 != 0: — The % operator finds the remainder. If it is not zero after division by 4, the year is not a leap year.
  3. return False — Immediately ends the function and sends False back to the code that called it.
  4. elif year % 100 != 0: — If the earlier condition was false, check whether the year is not divisible by 100.
  5. return True — Immediately ends the function and sends True back to the code that called it.
  6. elif year % 400 != 0: — For century years, check whether the year is not divisible by 400.
  7. return False — Immediately ends the function and sends False back to the code that called it.
  8. else: — Handles the remaining case when the preceding if/elif conditions were false.
  9. return True — Immediately ends the function and sends True back to the code that called it.

Task 8 — Write the testing loop

The loop visits each test index, calls days_in_month(), and compares the returned number with the expected answer. It prints OK if they match and Failed otherwise.

Indentation and alignment — exactly where to type

Start for at 0 spaces. Its ordinary body statements use 4 spaces. if and else both use 4 spaces; the print statements inside them use 8 spaces.

for i in range(len(test_years)):
    yr = test_years[i]
    mo = test_months[i]
    print(yr, mo, "-> ", end="")
    result = days_in_month(yr, mo)

What each line does

  1. for i in range(len(test_years)): — Repeats once per test year. The index i begins at 0 and advances through the parallel lists.

  3. mo = test_months[i] — Reads the month at the same position i so the year and month stay paired.
  4. print(yr, mo, "-> ", end="") — Prints the year, month, and arrow, keeping the cursor on the same line.
  5. result = days_in_month(yr, mo) — Calls days_in_month with the selected year and month, then stores the returned number.
  6. if result == test_results[i]: — Compares the actual answer with the expected answer at the same list position.
  7. print("OK") — Prints OK when the result matches the expected answer.
  8. else: — Handles the remaining case when the preceding if/elif conditions were false.

def is_year_leap(year):
    if year % 4 != 0:
        return False
    elif year % 100 != 0:
        return True
    elif year % 400 != 0:
        return False
    else:
        return True

def days_in_month(year, month):
    if year < 1582 or month < 1 or month > 12:
        return None
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    res = days[month - 1]
    if month == 2 and is_year_leap(year):
        res = 29
    return res

test_years = [1900, 2000, 2016, 1987]
test_months = [2, 2, 1, 11]
test_results = [28, 29, 31, 30]

for i in range(len(test_years)):
    yr = test_years[i]
    mo = test_months[i]
    print(yr, mo, "-> ", end="")
    result = days_in_month(yr, mo)
    if result == test_results[i]:
        print("OK")
    else:
        print("Failed")
