Quick Guide

Prime: A whole number greater than 1 divisible evenly only by 1 and itself. For example, 7 is prime; 8 is not because 8 ÷ 2 has no remainder.

Remainder: num % i == 0 means i divides num evenly.

Square root: num ** 0.5 computes a square root. int(...) removes its decimal part. The + 1 is necessary because range stops before its ending value.

Return: return False immediately exits the function if a divisor is found. return True happens only if the loop finishes without finding a divisor.

Example: For 9, the loop checks 2 and 3. Since 9 % 3 == 0, 9 is not prime.

Indentation Quick Reference — Read Before Coding

Python uses spaces at the beginning of lines to define code blocks. Use 4 spaces per level and do not mix tabs and spaces.

def example():              # 0 spaces
    if True:               # 4 spaces
        print("inside")    # 8 spaces
    print("after if")      # 4 spaces
print("outside function")   # 0 spaces

When a line ends in :, the following body must be indented. Lines at the same level should line up vertically.

What each line does

  1. def is_prime(num): — Creates the function and names its input num.
  2. if num < 2: — Checks for 0, 1, or negative numbers, which cannot be prime.
  3. return False — Immediately stops the function and reports that the number is not prime.

Task 3 — Check whether a divisor divides evenly

Inside the loop, check the remainder. If it is zero, the number is not prime.

Indentation and alignment

The for uses 4 spaces. Its if num % i == 0: uses 8 spaces. Its return False uses 12 spaces. That return belongs to the nested if, not the outer function-level if.

Code to type:

def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False

What each line does

  1. if num % i == 0: — Uses the modulo operator to test whether dividing by i leaves no remainder.
  2. return False — Stops the function as soon as one divisor is found.
  3. Example: For num = 8 and i = 2, 8 % 2 is 0, so the function returns False.

Task 4 — Return True when no divisor is found

Finish the function. If none of the loop’s checks returned False, the number is prime.

Indentation and alignment

Place return True at 4 spaces, aligned with for and the first if. Do not indent it inside the for loop: it must run only after the loop finishes.

Code to type:

def is_prime(num):
    if num < 2:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True

What each line does

  1. return True — Reports that no divisor was found and ends the function.
  2. Why alignment matters: If this return were inside the loop, Python could decide too early after testing just one divisor.
  3. Example: For 7, the loop checks 2; there is no exact divisor, so the loop finishes and returns True.

Complete Code — Review

Compare your completed program with the source guide. Make sure return True is aligned with the for line, and the testing loop begins at the left margin.

def is_prime(num):
    # Step 1: Check if the number is less than 2
    if num < 2:
        return False
    # Step 2: Check for divisors from 2 to the square root of num
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:  # If num is divisible by i, it is not prime
            return False
    # Step 3: Return True if no divisors were found
    return True

# Testing the function with numbers from 1 to 19
for i in range(1, 20):
    if is_prime(i):
        print(i, end=" ")
print()
