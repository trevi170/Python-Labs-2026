Quick Guide — Understanding Lists

A list stores multiple values in one variable. Square brackets [] hold the items, and commas separate them.

hat_list = [1, 2, 3, 4, 5]

Indexes begin at zero: the first item is index 0, the second is index 1, and the third is index 2.

Value:  1  2  3  4  5
Index:  0  1  2  3  4

hat_list[2] selects the third item, which is initially 3. Assigning a new value changes only that item.

hat_list[-1] refers to the last item, regardless of the list's length. del removes that item, and len(hat_list) counts how many items remain.

Scenario

Imagine a hat containing a list of five numbers: 1, 2, 3, 4, 5. Replace the middle number with an integer chosen by the user, remove the last number, and print the number of items remaining.

Follow an Example Before Coding

For illustration, suppose the user enters 9. The list changes as follows:

Starting list:        [1, 2, 3, 4, 5]
Replace index 2:      [1, 2, 9, 4, 5]
Delete last element:  [1, 2, 9, 4]
Remaining length:     4

The value 9 is only a practice example; the user can enter any integer.

Task 3 — Replace the Middle Element

Ask the user to enter an integer. input() receives text, so int() converts the entry to an integer. The assignment stores that integer in hat_list[2], replacing the original third item.

hat_list[2] = int(input("Enter an integer number: "))

Task 4 — Remove the Last Element

Use del to remove an item from the list. The index -1 selects the last item, so this statement removes the original number 5.

del hat_list[-1]

Task 5 — Print the List Length

Use len() to count how many elements remain after the deletion. The original list has five elements, and removing one leaves four.

print(len(hat_list))
