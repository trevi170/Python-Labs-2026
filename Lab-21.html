Essentials of the while loop — Building a Pyramid

Use a while loop to determine how many complete pyramid layers can be built from a given number of blocks.

Quick Guide

blocks stores the number of blocks that are still available.

height counts the number of fully completed pyramid layers.

in_layer stores how many blocks are required to build the current layer. It starts at 1 and increases by 1 after each completed layer.

while in_layer <= blocks: means: keep building while there are enough blocks available to finish the current layer.

+= adds to the current value. -= subtracts from the current value.

Scenario

Imagine you are helping a boy and his father, a computer programmer, build a flat pyramid using wooden blocks. Each layer has one block more than the layer above it. Your program must calculate the maximum height that can be built from the available blocks.

The height is the number of fully completed layers. If there are not enough blocks to complete the next layer, construction stops.

Task 1 — Read the Number of Blocks

Ask the user how many blocks are available and convert the entered value to an integer.

Code:

blocks = int(input("Enter the number of blocks: "))

Task 2 — Initialize the Variables

Set height to 0 because no layers have been completed yet. Set in_layer to 1 because the first layer needs one block.

Code:

height = 0
in_layer = 1

Task 3 — Create the while Loop

Continue building while there are enough remaining blocks to complete the current layer.

Code:

while in_layer <= blocks:

What this means: Python checks whether the blocks needed for the current layer are less than or equal to the blocks still available. If the condition is true, another complete layer can be built.

Task 4 — Build Each Layer

Inside the loop, increase the height, subtract the blocks used by the completed layer, and increase in_layer so the next layer requires one more block.

Code:

height += 1
blocks -= in_layer
in_layer += 1

Follow the changes: height += 1 records a completed layer, blocks -= in_layer removes the blocks that were used, and in_layer += 1 increases the size of the next layer.

Task 5 — Print the Pyramid Height

When there are not enough blocks to complete another layer, the loop stops. Print the number of fully completed layers.

Code:

print("The height of the pyramid:", height)

Task 6 — Test the Complete Program

Run the complete program with a positive number of blocks. Your output should show the maximum number of complete layers that can be built. Try more than one positive value so you can observe how the height changes.

Example Output Format:

The height of the pyramid: [calculated height]

Complete Code — Review

blocks = int(input("Enter the number of blocks: "))

height = 0
in_layer = 1

while in_layer <= blocks:
    height += 1
    blocks -= in_layer
    in_layer += 1

print("The height of the pyramid:", height)
