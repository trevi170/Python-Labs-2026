Quick Guide — Conditional Execution

A conditional lets your program make a decision. Python checks a condition and runs a particular block of code depending on whether that condition is True or False.

if — checks the first condition.
elif — checks another condition if the previous condition was False.
else — runs when none of the previous conditions were True.
== — asks whether two values are equal.

Important: Python strings are case-sensitive. "Spathiphyllum", "spathiphyllum", and "SPATHIPHYLLUM" are three different strings.

Lab Scenario

Spathiphyllum, commonly known as a peace lily, is a popular indoor plant. In this activity, your program is a big fan of Spathiphyllum and will respond differently depending on exactly what the user types.

If the user enters Spathiphyllum → print Yes - Spathiphyllum is the best plant ever!

If the user enters spathiphyllum → print No, I want a big Spathiphyllum!

For anything else → print Spathiphyllum! Not [input]!

Task 1 — Capture User Input

Create Lab13.py. Use input() to ask the user for a flower name and store the response in a variable named name.

name = input("Enter flower name: ")

Why isn't int() or float() needed? The program is working with words, and input() already returns a string.

Task 2 — Check for Exact "Spathiphyllum"

Start the decision structure with an if statement. The == operator compares the user's input with the exact string "Spathiphyllum".

if name == "Spathiphyllum": print("Yes - Spathiphyllum is the best plant ever!")

Notice the colon (:) after the condition and the indentation before print(). The indented line belongs to the if block.

Task 3 — Add the elif Condition

If the first condition is False, Python should check whether the user entered the lowercase version "spathiphyllum".

elif name == "spathiphyllum": print("No, I want a big Spathiphyllum!")

elif means “else if.” Python reaches this condition only when the first if condition was False.

Task 4 — Handle Every Other Input

Add an else block. It does not need another condition because it handles anything that did not match the first two choices.

else: print("Spathiphyllum! Not", name + "!")

The variable name allows the program to include the user's actual input in the message.
