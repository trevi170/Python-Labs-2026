Quick Guide — Comparison Operators and Boolean Results

A comparison operator asks Python a question about two values. Python answers that question with one of two Boolean values: True or False.

>= greater than or equal to
<= less than or equal to
> greater than
< less than
== equal to
!= not equal to

For example, 150 >= 100 is True, while 55 >= 100 is False.

Lab Scenario

You will create a short Python program that asks the user to enter an integer. The program will then ask Python, in effect, “Is this number greater than or equal to 100?”

Python will evaluate the comparison and display either True or False.

Task 1 — Read the Input

Create Lab12.py. Use input() to ask the user for a number, and use int() to convert the entered text into an integer. Store the result in a variable named n.

n = int(input("Enter a number: "))

What is happening? input() returns text. int() converts that text into an integer so it can be compared numerically.

Task 2 — Compare the Number with 100

Use the >= operator to determine whether the value stored in n is greater than or equal to 100.

n >= 100

How to read it: “Is n greater than or equal to 100?” The answer can only be True or False.

This task is for understanding the comparison, so no separate screenshot is required here.

Task 3 — Print the Boolean Result

Place the comparison directly inside print(). Python evaluates the comparison first and then displays its Boolean result.

print(n >= 100)

Your complete program now contains only two lines:

n = int(input("Enter a number: ")) print(n >= 100)

Task 4 — Test the Program

Run the program four times. Enter each sample value and confirm that your output matches the expected Boolean result.

Test Data

Notice that 100 produces True because >= means greater than OR equal to.
