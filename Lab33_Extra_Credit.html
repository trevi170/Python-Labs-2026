Lab 33 Extra Credit: Detecting Failed Login Attempts

Build a simple security alert tool using Python functions, dictionaries, and loops.

Learning Objectives

Count failed login attempts by username using a dictionary, write a function to identify suspicious activity, and generate alerts. Use only the fictional data provided; no real accounts or network access are needed.

In a real security operations center (SOC), repeated failures may indicate password guessing, but can also result from ordinary mistakes. Three attempts is a classroom threshold, not a universal security rule.

TASK 1

Create sample login data

Enter the following code. Each tuple represents a username and a login result.

logs = [("alice", "failed"), ("bob", "success"),
        ("alice", "failed"), ("alice", "failed"),
        ("bob", "failed"), ("carol", "success")]
failed = {}
Line-by-line and indentation guide

• 0 spaces: logs starts at the left edge. It is a list of tuples.

• The next two lines continue the list inside brackets; align them for readability.

• Each tuple contains a username and a login status.

• 0 spaces: failed = {} creates an empty dictionary to hold counts.

TASK 2

Count failed logins

Add the following code below your existing code. Do not delete earlier code.

for user, status in logs:
    if status == "failed":
        failed[user] = failed.get(user, 0) + 1
Line-by-line and indentation guide

• 0 spaces: for unpacks each tuple into user and status.

• 4 spaces: if checks whether the login failed; successful logins are ignored.

• 8 spaces: failed.get(user, 0) retrieves the current count or starts at zero. Adding 1 records another failure.

TASK 3

Generate security alerts

Add the following code below the loop. Run the entire program using python Lab33.py (or python3 Lab33.py).

def is_suspicious(count):
    return count >= 3

for user, count in failed.items():
    print(user, "failed attempts:", count)
    if is_suspicious(count):
        print("ALERT: Review account", user)
Line-by-line and indentation guide

• 0 spaces: def creates a function with one parameter, count.

• 4 spaces: return sends True when the count is at least 3, otherwise False.

• 0 spaces: the second for loop reads each username and count from the dictionary.

• 4 spaces: print displays the count; if calls the function to decide whether an alert is needed.

• 8 spaces: the final print runs only when the condition is True.
