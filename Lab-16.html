Essentials of the while loop — Guess the secret number

Create a guessing game that keeps asking until the player finds the secret number.

Before You Begin

Python filename: Lab16.py

You may use your preferred Python IDE. GitHub Codespaces is recommended.

Type the program code manually.

Objectives

  • Understand the basics of using the while loop in Python.
  • Continuously ask for user input until the correct condition is met.
  • Practice interactive programming with a guessing game.

Quick Guide

while repeats code while its condition is true. != means “not equal to.” Therefore, user_number != secret_number keeps the loop running while the guess is wrong. The indented statements underneath while repeat. When the player enters 777, the condition becomes false and the program continues after the loop.

Scenario

A magician has chosen a secret number. Your program keeps asking the player for guesses until the correct number is entered. The player remains in the loop until they succeed and break free.

Task 1 — Set Up the Secret Number

Create secret_number and set it to 777.

secret_number = 777

Task 2 — Welcome the Player

Use triple quotes to print the multi-line welcome message.

print("""
+================================+
| Welcome to my game, muggle!   |
| Enter an integer number       |
| and guess what number I've    |
| picked for you.               |
| So, what is the secret number?|
+================================+
""")

Task 3 — Take User Input

Ask for the player's guess and convert it to an integer.

user_number = int(input("Enter the number: "))

Task 4 — Create the Loop

Keep asking while the guess is different from the secret number.

while user_number != secret_number:
    print("Ha ha! You're stuck in my loop!")
    user_number = int(input("Enter the number again: "))

Task 5 — Break Free

After the correct guess ends the loop, print the victory message.

print(secret_number, "Well done, muggle! You are free now.")

Final test: Enter at least one wrong number first, then enter 777 so your screenshot shows the loop repeating and then ending.
