The break statement — Stuck in a loop

Use while True and break to keep asking for input until the correct secret word is entered.

Quick Guide

while True: creates a loop whose condition is always true. It continues until something explicitly ends it.

input() asks the user to enter information.

== checks whether two values are equal. Here, Python checks whether the entered word equals "chupacabra".

break immediately exits the current loop. After the loop ends, Python continues with the first statement after the loop.

Indentation matters: the input and if statements belong inside the loop. The final success message belongs outside the loop.

Scenario

Your program will use a while loop to keep asking the user for a word unless the user enters the secret word “chupacabra.” When the correct secret word is entered, the program prints “You've successfully left the loop!” and stops running.

Task 2 — Get User Input

Inside the loop, ask the user to enter a word and store it in the variable word. This line must be indented because it belongs to the loop.

Code:

word = input("You're stuck in an infinite loop!\nEnter the secret word to leave the loop: ")

Task 3 — Check for the Exit Word

Use an if statement to check whether the word is exactly "chupacabra". If it matches, use break to exit the loop.

Code:

if word == "chupacabra":
    break

Task 4 — Print the Success Message

After the loop ends, print the success message. This statement should not be indented under the loop.

Code:

print("You've successfully left the loop!")

Task 5 — Test the Complete Program

Run the completed program. Enter apple, then banana, and finally chupacabra. The program should keep asking until the secret word is entered.
