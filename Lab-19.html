The continue statement — The Ugly Vowel Eater

Use continue to skip vowels while processing the letters in a word.

Objectives

  • Learn how the continue statement works in loops.
  • Understand conditional execution using if-elif-else.
  • Create a program that skips certain characters (vowels) and processes others.

Quick Guide

.upper() converts a string to uppercase. This allows the program to compare every letter against uppercase vowels.

for letter in user_word: examines the word one character at a time.

if / elif / else checks whether the current letter matches one of the vowels.

continue skips the rest of the current loop iteration and moves immediately to the next letter.

In this lab, vowels are skipped. Letters that reach the else block are printed.

Scenario

Create a program called Vowel Eater. The program takes a word from the user, converts it to uppercase, removes the vowels A, E, I, O, U by skipping them, and prints the remaining letters. Each remaining letter is printed on a new line.

Task 1 — Ask for User Input

Ask the user to enter a word and store the response in a variable named user_word.

Code:

user_word = input("Enter your word: ")

Task 2 — Convert the Word to Uppercase

Convert the entered word to uppercase. This makes it easier to compare every letter with the uppercase vowels A, E, I, O, and U.

Code:

user_word = user_word.upper()

Task 3 — Loop Through Each Letter

Use a for loop to examine each character in user_word. The variable letter will hold one character at a time.

Code:

for letter in user_word:

Task 4 — Skip the Vowels

Inside the loop, use if and elif to check each vowel. When a vowel is found, continue skips the rest of that loop iteration and moves to the next letter.

Code:

if letter == "A":
    continue
elif letter == "E":
    continue
elif letter == "I":
    continue
elif letter == "O":
    continue
elif letter == "U":
    continue

Task 5 — Print the Remaining Letters

Add an else block. If the current character is not a vowel, print it. Because print(letter) runs once per iteration, each remaining letter appears on a new line.

Code:

else:
    print(letter)

Final test: Run the complete program with a word that contains both vowels and consonants. Verify that the vowels are skipped and only the remaining letters are printed, one per line.
