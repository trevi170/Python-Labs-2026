Quick Guide — Operators and Order of Operations

Operators are symbols that tell Python to perform calculations. In this lab, you will mainly use division (/) and addition (+).

Operator precedence means Python follows an order when solving an expression. Parentheses are evaluated first, followed by the remaining operations according to Python's rules.

Associativity describes the direction Python uses when operators have the same priority. The parentheses in this lab make the intended order clear.

Lab Scenario

Your task is to complete a Python program that evaluates a mathematical expression. The program will ask the user to enter a value for x, calculate a value for y, and display the result.

Because the expression contains several calculations inside one another, pay close attention to the parentheses and the order in which Python performs each operation.

Task 1 — Input the Value

Create Lab10.py. Use input() to ask the user for a value and float() to convert the input into a number Python can use in calculations.

x = float(input("Enter a value: "))

What is happening? input() receives what the user types as text. float() converts that text into a floating-point number and stores it in x.

Task 2 — Understand the Expression

The expression is nested, meaning one calculation appears inside another. Read it from the innermost parentheses outward.

Expression:
y = 1 / (x + 1 / (x + 1 / (x + 1 / x)))

The deepest calculation is 1 / x. Python uses that result in the next set of parentheses and continues outward until it calculates y.

Task 3 — Write the Expression in Python

Assign the complete expression to a variable named y. Type the line carefully. Every opening parenthesis must have a matching closing parenthesis.

y = 1 / (x + 1 / (x + 1 / (x + 1 / x)))

Why are parentheses important? They tell Python how the parts of the expression are grouped. Changing or removing them can change the result.

Task 4 — Print the Result

After Python calculates y, display the result using print().

print("y =", y)

The text y = is a label, and the second argument displays the value stored in y.
