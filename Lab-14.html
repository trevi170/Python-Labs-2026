Quick Guide — The if-else Statement

An if-else statement allows Python to choose between two paths. Python checks the if condition first. If it is True, the indented code under if runs. Otherwise, the indented code under else runs.

<= means less than or equal to.
< means less than.
* means multiply.
- means subtract.
round(value, 0) rounds a number to 0 decimal places.

Lab Scenario

You are creating a Personal Income Tax (PIT) calculator for a fictional land of milk and honey. The tax depends on the person's annual income.

If income is not higher than 85,528 dollars:
Tax = 18% of the income minus 556.02 dollars.

If income exceeds 85,528 dollars:
Tax = 14,839.02 dollars plus 32% of the amount above 85,528.

The program must also make sure the tax is never negative and must round the final tax to the nearest whole dollar.

Task 1 — Accept the Annual Income

Create Lab14.py. Ask the user for annual income and convert the entered value to a floating-point number.

income = float(input("Enter the annual income: "))

Why float()? Income may contain a decimal value. float() converts the text returned by input() into a number Python can use in calculations.

Task 2 — Calculate the Tax with if and else

Use if to check whether the income is less than or equal to 85,528. If it is, use the 18% formula. Otherwise, use else and the higher-income formula.

if income <= 85528: tax = income * 0.18 - 556.02 else: tax = (income - 85528) * 0.32 + 14839.02

How it works: Only one of these two formulas runs. An income of exactly 85528 uses the first formula because the condition includes “equal to.”

Task 3 — Prevent a Negative Tax

For a very low income, the first formula can produce a negative value. Tax should never be negative, so add another if statement.

if tax < 0.0: tax = 0.0

This is a separate check performed after the tax calculation. If the calculated tax is below zero, Python replaces it with 0.0.

Task 4 — Round and Print the Tax

Round the tax to zero decimal places and then display the result.

tax = round(tax, 0) print("The tax is:", tax, "dollars")

For example, a calculated tax containing cents is rounded to the nearest whole dollar before it is printed.
